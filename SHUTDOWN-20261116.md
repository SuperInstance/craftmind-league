## Revival — how a future session brings the world back

1. Clone https://github.com/SuperInstance/craftmind-world — it holds
   `world/`, `world-26.3-backup/`, and the Paper/server text configs.
2. Install a Paper runtime: the jar was excluded as reinstallable
   bulk; `version_history.json` in the repo records the build
   (paper-26.3-242). You need a JDK 25 (the Orin ran
   `~/jdk-25/bin/java -Xms1G -Xmx2G`).
3. Restore `server.properties` from the archive:
   Thor `~/games-away-archive/secrets/orin-league-server.properties`.
   Without it the management-server secret fields are unset.
4. Lay out the server directory (world/ at the root beside the jar,
   configs as in the repo), start with `nogui`. The citizens are in
   `world/players/data/` — Cody's save is the one whose last position
   is the pocket mouth (66.31, 63, −91.3).
5. On the Orin, the old user unit still exists, disabled, at
   `~/.config/systemd/user/minecraft-paper.service` —
   `systemctl --user enable --now minecraft-paper` revives the exact
   former arrangement (it expects the server at `~/minecraft-server`
   and the JDK at `~/jdk-25`).
6. The league around it: clone craftmind-league for the record,
   drivers, floor and Director files; the bot repos' full histories
   are in the archive's `nested-bot-repos/`; the Thor league timers
   (`game-master`, `league-meta-watcher`) and the Orin heartbeat
   timer remain installed but disabled on their boxes.
